# Zad | زَاد 🌙

**Zad (زاد)** is a comprehensive Islamic mobile application built with **Flutter** to assist Muslims in their daily spiritual routines. The app provides a smooth, modern UI for accessing the Holy Quran, daily Azkar, Asmaa Allah Al-Husna (the 99 Names of Allah), prayer times, and Islamic calendar tracking.

## ✨ Features

* 📖 **The Holy Quran (القرآن الكريم):** Clear reading layout with surah navigation.
* 📿 **Daily Azkar & Supplications (الأذكار والأدعية):** Categorized morning, evening, and post-prayer supplications.
* ✨ **Asmaa Allah Al-Husna (أسماء الله الحسنى):** Beautiful presentation of the 99 Names of Allah with their meanings.
* 🎨 **Modern & Responsive UI:** Clean design optimized for various device screen sizes.
